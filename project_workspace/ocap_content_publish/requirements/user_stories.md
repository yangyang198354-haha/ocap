# 信息公开发布与多平台内容中心 — 用户故事

编号接续基线（现有最大号 US-104，来自 ocap_registry_import），本批从 US-105 起。依据 requirements_spec.md 0.3.0（用户已确认需求，"需求确认，拆用户故事"）。

约定：
- 优先级与 spec 一致：Must Have / Should Have。故事点为相对估算（Fibonacci），均标 [ESTIMATE]，供开发评估，不作承诺。
- 外部平台（微信公众号、小红书、今日头条、火山方舟、DeepSeek、即梦）的接口能力均 [UNSOURCED]（spec C-26、C-30）。AC 只写产品行为："调用已配置的服务""平台返回成功 / 失败"，不写接口事实。哪些平台自动保存、哪些走人工粘贴待 P11-3，故 AC 用"有可用草稿接口的平台""无可用草稿接口的平台"表述，测试时由替身指定。
- 素材规格按 spec C-29（Q-CP-14=A）：图片单个不超过 10 MB、格式 jpg/jpeg、png；视频单个不超过 10 MB（视频格式清单与大小是否合适见 spec OQ-6，未定）。素材库总配额用户未给，不写 AC。
- 信息公开面向 Web 前台门户和微信小程序两端展示（Q-CP-01=B）；涉及展示的故事分别覆盖两端。
- 视频生成、平台保存等需要外部服务的功能，测试只用替身，不调用真实平台（画像 P4）。

## 用户故事

### US-105: 创建并发布信息公开
- 故事：As a 后台管理员, I want to 在管理后台编写标题和正文，保存草稿并确认发布信息公开, so that 业主能看到公开信息，且不必经业委会审批
- 关联需求：REQ-FUNC-099、REQ-NFUNC-017；优先级：Must Have；故事点：5 [ESTIMATE]
- AC-105-01：Given 管理员已登录后台 / When 填写标题和正文并点击"保存草稿" / Then 该内容状态为"草稿"，管理员可在列表中看到，登录用户在门户和小程序均看不到它
- AC-105-02：Given 一条状态为"草稿"的内容 / When 管理员点击"发布"并确认 / Then 状态变为"已发布"，无需任何审批步骤，且审计日志新增 1 条记录，含操作人、对象、时间、结果四项
- AC-105-03：Given 管理员新建内容 / When 标题为空或正文为空时点击"发布" / Then 发布被拒绝，页面提示缺失的是标题还是正文，内容状态不变为"已发布"

### US-106: 修改、下线、删除已发布的信息公开
- 故事：As a 后台管理员, I want to 修改、下线或删除已发布的信息公开, so that 公开内容能及时更正或撤下
- 关联需求：REQ-FUNC-099、REQ-NFUNC-017；优先级：Must Have；故事点：3 [ESTIMATE]
- AC-106-01：Given 一条已发布内容 / When 管理员修改正文并重新发布 / Then 门户和小程序展示修改后的正文，审计日志新增 1 条"修改"记录
- AC-106-02：Given 一条已发布内容 / When 管理员点击"下线" / Then 状态变为"已下线"，已登录用户在门户和小程序的列表与详情中均不再看到它，审计日志新增 1 条记录
- AC-106-03：Given 一条内容 / When 管理员点击"删除"并在二次确认中取消 / Then 内容仍然存在，审计日志不新增删除记录
- AC-106-04：Given 一条内容 / When 管理员点击"删除"并确认 / Then 该内容从管理列表消失，门户和小程序均不可访问，审计日志新增 1 条"删除"记录

### US-107: 在 Web 门户查看信息公开
- 故事：As a 已登录用户（含游客身份）, I want to 在 Web 前台门户查看管理员发布的信息公开, so that 我能了解小区公开信息
- 关联需求：REQ-FUNC-100、REQ-NFUNC-018；优先级：Must Have；故事点：3 [ESTIMATE]
- AC-107-01：Given 管理员已发布一条含加粗、居中、红色文字和超链接的内容 / When 已登录用户（含游客身份）在门户打开该内容 / Then 页面展示标题和正文，加粗、居中、红色文字和超链接均与编辑时一致，点击超链接跳转到所设地址
- AC-107-02：Given 门户中有多条已发布内容 / When 已登录用户打开信息公开列表 / Then 只列出状态为"已发布"的内容，不含草稿和已下线内容
- AC-107-03：Given 用户未登录 / When 访问信息公开列表或详情 / Then 不展示任何信息公开内容，页面跳转到登录页
- AC-107-04：Given 管理员发布的正文中夹带一段脚本片段 / When 已登录用户在门户打开该内容 / Then 脚本执行次数为 0，其余格式（文字、对齐、颜色）仍保留

### US-108: 在小程序查看信息公开
- 故事：As a 已登录用户（含游客身份）, I want to 在微信小程序查看管理员发布的信息公开, so that 我随时用手机了解小区公开信息
- 关联需求：REQ-FUNC-100、REQ-NFUNC-018；优先级：Must Have；故事点：3 [ESTIMATE]
- AC-108-01：Given 管理员已发布一条含加粗、居中、红色文字、图片和超链接的内容 / When 已登录用户（含游客身份）在小程序打开该内容 / Then 页面展示标题和正文，加粗、居中、红色文字和图片与编辑时一致，超链接可见并可点击
- AC-108-02：Given 管理员下线了一条内容 / When 已登录用户刷新小程序信息公开列表 / Then 列表中不再出现该内容
- AC-108-03：Given 用户未登录小程序 / When 进入信息公开页面 / Then 不展示信息公开内容，引导到登录
- AC-108-04：Given 管理员发布的正文中夹带一段脚本片段 / When 已登录用户在小程序打开该内容 / Then 脚本执行次数为 0，其余格式保留

### US-109: 编辑文字的段落、对齐、颜色和超链接
- 故事：As a 后台管理员, I want to 像微信公众号编辑页一样设置段落、对齐方式、文字颜色并插入超链接, so that 信息公开的版面符合我的设计
- 关联需求：REQ-FUNC-101；优先级：Must Have；故事点：3 [ESTIMATE]
- AC-109-01：Given 管理员在编辑器中选中一段文字 / When 分别设置"居中"对齐和某一文字颜色 / Then 编辑区与预览中该段显示居中和所选颜色，保存后重新打开仍保持
- AC-109-02：Given 管理员选中文字 / When 添加超链接并填入有效网址 / Then 该文字显示为链接，预览中点击跳转到该网址
- AC-109-03：Given 管理员添加超链接 / When 网址为空或格式明显无效 / Then 链接不被添加，页面提示"网址无效"
- AC-109-04：Given 管理员在编辑器中按回车 / When 连续输入两段文字 / Then 两段文字分属两个段落，各自可单独设置对齐

### US-110: 基础格式清单中的其余编辑功能
- 故事：As a 后台管理员, I want to 使用与公众号编辑页等价的基础格式功能, so that 我无需借助其他编辑工具
- 关联需求：REQ-FUNC-102；优先级：Must Have；故事点：5 [ESTIMATE]
- AC-110-01：Given 管理员在编辑器中 / When 查看工具栏 / Then 提供且仅提供基础格式清单的功能：标题层级、段落与行距、加粗、斜体、下划线、删除线、对齐、字号、文字色与背景色、超链接、有序列表、无序列表、引用、分割线、图片、视频、撤销、重做、清除格式
- AC-110-02：Given 管理员对一段文字应用了加粗、字号和背景色 / When 点击"清除格式" / Then 该段回到默认样式，文字内容不变
- AC-110-03：Given 管理员做了两步编辑 / When 点击"撤销"一次再点击"重做"一次 / Then 内容依次回到上一步状态和重做后的状态
- AC-110-04：Given 管理员查看工具栏 / When 寻找表格、代码块、公式、表情、卡片 / Then 这些功能不出现（本批不纳入）

### US-111: 在正文中插入图片和视频
- 故事：As a 后台管理员, I want to 在正文中插入素材库已有的或当场上传的图片和视频, so that 内容图文并茂
- 关联需求：REQ-FUNC-103；优先级：Must Have；故事点：3 [ESTIMATE]
- AC-111-01：Given 素材库中有一张图片 / When 管理员在编辑器中选择"从素材库插入"并选中它 / Then 正文光标处出现该图片，保存后门户和小程序均能显示
- AC-111-02：Given 管理员当场上传一张 jpg 图片，大小 3 MB / When 上传完成 / Then 图片插入正文，同时素材库新增 1 条来源为"上传"的图片素材
- AC-111-03：Given 管理员上传图片 / When 文件格式为 svg，或单个文件超过 10 MB / Then 上传被拒绝，提示格式或大小不符合要求，正文和素材库均无变化

### US-112: 配置版式样式并预览
- 故事：As a 后台管理员, I want to 为文字内容选用或自定义版式样式模板并在发布前预览, so that 内容有统一的美观排版
- 关联需求：REQ-FUNC-104；优先级：Must Have；故事点：5 [ESTIMATE]
- AC-112-01：Given 系统内置了若干套样式模板 / When 管理员为一条内容选用其中一套并点击"预览" / Then 预览按该模板的字体、间距、颜色等版式显示，内容文字不变
- AC-112-02：Given 管理员自定义一套样式并保存为模板 / When 在另一条内容中选择该模板 / Then 该自定义模板出现在选择列表中，选用后预览与自定义时一致
- AC-112-03：Given 管理员在正文中插入"分页标记" / When 预览 / Then 预览在该位置分页
- AC-112-04：Given 自定义样式的名称为空 / When 点击保存 / Then 保存被拒绝并提示"模板名称不能为空"

### US-113: 在门户和小程序按页阅读长内容
- 故事：As a 已登录用户（含游客身份）, I want to 在 Web 门户和小程序按页阅读较长的信息公开, so that 长文阅读不费力
- 关联需求：REQ-FUNC-104；优先级：Must Have；故事点：3 [ESTIMATE]
- AC-113-01：Given 一条已发布内容含 1 个分页标记，把正文分为两部分 / When 已登录用户在 Web 门户阅读 / Then 第一页只显示分页标记之前的部分，页面有页码或"下一页"控件，点击后显示第二部分
- AC-113-02：Given 同一条内容 / When 已登录用户在小程序阅读 / Then 与 Web 门户分页位置一致，可翻到下一页和上一页
- AC-113-03：Given 一条内容篇幅超过所用样式模板配置的页长 / When 已登录用户阅读 / Then 内容按该页长自动分页，最后一页显示剩余内容，页长的具体数值待用户确认（spec OQ-2）
- AC-113-04：Given 一条内容不含分页标记且篇幅不超过页长 / When 阅读 / Then 只有 1 页，不显示"下一页"控件

### US-114: 用提示词让 agent 生成文案并复用提示词模板
- 故事：As a 后台管理员, I want to 输入提示词并选择生成参数让 agent 生成文案，并把提示词保存为模板复用, so that 我不用从头写稿
- 关联需求：REQ-FUNC-105；优先级：Must Have；故事点：5 [ESTIMATE]
- AC-114-01：Given 已有至少一个可用的大语言模型配置 / When 管理员输入提示词、选择模型并点击"生成" / Then 系统调用该已配置的模型，返回的文案显示在生成结果区
- AC-114-02：Given 管理员输入了一段提示词 / When 点击"保存为模板"并命名 / Then 提示词模板列表新增 1 项，之后可选中它，提示词自动填入
- AC-114-03：Given 管理员未输入提示词（空白） / When 点击"生成" / Then 不发起生成，提示"请输入提示词"
- AC-114-04：Given 模型服务返回失败 / When 管理员点击"生成" / Then 页面显示失败及失败原因，不产生内容草稿，已输入的提示词保留
- AC-114-05：Given 系统中没有任何可用的大语言模型配置 / When 管理员点击"生成" / Then 不发起生成，提示"请先配置大语言模型"

### US-115: 把生成的文案放入编辑器并存为草稿
- 故事：As a 后台管理员, I want to 把 agent 生成的文案放进编辑器继续修改，并先保存为草稿, so that 我确认后才发布
- 关联需求：REQ-FUNC-108；优先级：Must Have；故事点：3 [ESTIMATE]
- AC-115-01：Given agent 已返回生成文案 / When 管理员点击"放入编辑器" / Then 编辑器正文填入该文案，管理员可继续编辑，内容状态为"草稿"
- AC-115-02：Given 内容由生成文案放入且未点发布 / When 登录用户查看门户和小程序 / Then 看不到该内容
- AC-115-03：Given 编辑器中已有管理员手写的未保存内容 / When 管理员点击"放入编辑器" / Then 系统先提示"将覆盖当前正文"，管理员取消时原正文不变

### US-116: 生成图文并茂的内容与配图
- 故事：As a 后台管理员, I want to 让 agent 生成带配图的内容，可使用 AI 文生图，也可从素材库选图, so that 内容图文并茂
- 关联需求：REQ-FUNC-106；优先级：Must Have；故事点：5 [ESTIMATE]
- AC-116-01：Given 已配置图像生成服务 / When 管理员为一段文案点击"AI 生成配图"并给出描述 / Then 系统调用已配置的图像生成服务，成功时生成的图片显示在结果区，管理员可选择插入正文
- AC-116-02：Given 图像生成成功 / When 管理员点击"保存到素材库" / Then 素材库新增 1 条来源为"AI 生成"的图片素材
- AC-116-03：Given 管理员不想用 AI 配图 / When 从素材库选一张图片作为配图 / Then 该图片插入文案对应位置
- AC-116-04：Given 图像生成服务返回失败 / When 管理员点击"AI 生成配图" / Then 页面显示失败及失败原因，正文与素材库不变

### US-117: 配置大语言模型服务
- 故事：As a 后台管理员, I want to 配置 agent 使用的火山方舟或 DeepSeek 模型（全站一份）, so that 所有管理员都能用同一套模型生成文案
- 关联需求：REQ-FUNC-109、REQ-NFUNC-016、REQ-NFUNC-017；优先级：Must Have；故事点：3 [ESTIMATE]
- AC-117-01：Given 管理员打开模型配置页 / When 首次进入 / Then 页面可添加火山方舟模型或 DeepSeek 模型，默认选用 DeepSeek 对话模型
- AC-117-02：Given 管理员保存了一份模型配置（含 API 凭据） / When 再次打开配置页或查询配置接口 / Then 凭据字段不回显原文，仅可覆盖更新；凭据原文在页面、接口响应、日志和审计记录中出现次数均为 0
- AC-117-03：Given 管理员 A 保存了配置 / When 另一位管理员 B 登录打开生成页 / Then B 可选用同一份配置，不需要再配置
- AC-117-04：Given 管理员保存配置 / When 修改了模型或凭据 / Then 审计日志新增 1 条配置变更记录，含操作人、对象、时间、结果，但不含凭据原文
- AC-117-05：Given 系统中未配置任何模型 / When 管理员进入生成页 / Then 生成按钮不可用或点击时被拒绝，提示"请先配置大语言模型"

### US-118: 测试模型配置连通性
- 故事：As a 后台管理员, I want to 对已保存的模型配置执行测试连通，仅测试成功的配置可用于生成, so that 避免选到不可用的模型
- 关联需求：REQ-FUNC-110、REQ-NFUNC-017；优先级：Should Have；故事点：2 [ESTIMATE]
