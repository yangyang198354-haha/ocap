需求分批输入。流程：每批需求先整理（PHASE_01），用户确认后再整理成用户故事（PHASE_02）。后续大阶段需用户逐一明确放行。
- 2026-11-07 "先开始进行架构设计，但是不要开发" → 放行 GROUP_B。
- 2026-11-07 "接着把开发测试做完" → 放行 GROUP_C/D；2026-11-08 用户授权测试环境部署（E2 已完成，远端从内网机器执行）。

**Why:** 用户原话（2026-11-07）："先整理这些需求。确认后再整理成用户故事。但是不要开始设计、开发。我把所有的需求输入完毕后。我让开始再开始。" 之后逐步放行。

**How to apply:** 新一批需求仍按"先整理、确认后出故事、再逐阶段放行"处理。技术选型参考 Freeark（yangyang198354-haha/Freeark，本地 /root/myproject/Freeark）。git 提交与部署都需用户在当轮明确同意，不可复用。
