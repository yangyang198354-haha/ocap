## 角色（本批次出现）

| 角色 | 定义（来源） |
|---|---|
| 访客（未登录） | 尚未登录或注册的使用者 |
| 注册用户 | 已完成注册的账号。通过清册认证前为"游客"：`"其他的注册用户为游客"` |
| 产权业主 | 通过业主清册手机号认证的注册用户：`"可以直接认证为产权业主"`；一个专有部分可有多名产权业主（用户答复 Q3，2026-11-07） |
| 户主 | 某专有部分第一个认证的产权业主：`"第一个认证的产权业主默认为户主"`；每个专有部分有且只有一个户主（用户答复 Q18，2026-11-07） |
| 同住人 | 经该专有部分产权业主审批通过的注册用户：`"产权业主可以审批，通过其为同住人"` |
| 游客 | 未通过清册认证、也不是同住人的注册用户 |
| 管理员 | 管理后台的使用者：维护业主清册（批量导入、单条修改），审核产权认证申诉。来源：用户答复 Q10=B、Q4=B（2026-11-07）。管理员不是注册用户：账号由系统初始化或已有管理员创建，独立账号 + 密码登录管理后台（用户答复 Q25=A，2026-11-07；见 REQ-FUNC-025） |
