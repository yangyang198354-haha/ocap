> 故事点均为相对估算 `[ESTIMATE]`，供开发评估，不作承诺。已由用户答复定稿的规则直接写成 Then（标注"Q-IP-NN=X"）；仍待确认的 Q-IP-15~18 按推荐项暂定并注明"按 Q-IP-NN 暂定"，用户改答后只改对应 AC 的 Then。

### US-232: 在"我的身份与房屋"页看到每套房屋的类型与面积，主页不再重复展示
- 故事：As a 已登录的用户（游客/同住人/产权业主）, I want to 在"我的身份与房屋"页面一次看到我每套房屋的名称、类型、面积和我与它的关系, so that 不必在主页两张重复的"认证房屋"卡片之间来回看
- 关联需求：REQ-FUNC-224、REQ-FUNC-226；优先级：Must Have；故事点：5 [ESTIMATE]
- AC-232-01：Given 用户是"1栋1单元9层902号"（住宅，面积已登记）的产权业主，同时是"2栋2单元3层301号"（公寓，面积已登记）的同住人 / When 打开"我的身份与房屋"页面 / Then 页面显示汇总身份标签，且恰有 2 行房屋，每行包含专有部分名称、类型（"住宅"/"公寓"）、面积（带"㎡"）、关系标签（"产权业主"/"同住人"）；"1栋…"行显示同住人名单与"移除"（如有同住人），"2栋…"行显示"退出"按钮
- AC-232-02：Given 某套房屋的类型或面积在清册中未登记 / When 打开该页 / Then 该行类型或面积位置显示"未登记"，不显示空白、"null"或"0"
- AC-232-03：Given 用户没有任何有效房屋关系（其历史关系均已撤销或结束） / When 打开该页 / Then 页面显示"暂无已认证房屋"，房屋行数为 0，已撤销的专有部分不出现，并显示 REQ-FUNC-231 的提醒
- AC-232-04：Given 用户已认证 2 套房 / When 登录后进入主页 / Then 主页中不存在按套列出专有部分名称、类型、面积的卡片；主页保留的"认证房屋"小卡片数字为 2，点击后进入"我的身份与房屋"页面（Q-IP-02=A）
- AC-232-05：Given 房屋信息接口请求失败（异常路径） / When 打开该页 / Then 页面显示"加载失败，请重试"及重试入口，不显示"暂无已认证房屋"，也不显示"游客"身份

### US-234: 产权业主在"我的身份与房屋"页底部审批同住人申请，其他人看不到
- 故事：As a 产权业主, I want to 在"我的身份与房屋"页面最底部看到并处理申请加入我名下专有部分的同住人申请, so that 审批入口集中且只有有权审批的人能看到
- 关联需求：REQ-FUNC-227、REQ-NFUNC-042；优先级：Must Have；故事点：5 [ESTIMATE]
- AC-234-01：Given 用户是"1栋1单元9层902号"的产权业主，该专有部分有 1 条待审批同住人申请 / When 打开"我的身份与房屋"页 / Then 页面最后一个卡片标题为"待我审批的同住人申请"，含 1 行（申请人昵称或账号 → 专有部分、申请时间、"通过"、"拒绝"按钮）
- AC-234-02：Given 同上 / When 点击"通过" / Then 提示"已处理"，该行从卡片消失，卡片显示"暂无待审批的同住人申请"，数量提示更新为 0
- AC-234-03：Given 用户是产权业主但当前无待审批申请 / When 打开该页 / Then 页面底部仍显示该卡片，内容为"暂无待审批的同住人申请"
- AC-234-04：Given 用户是游客，或仅是同住人而不是任何专有部分的产权业主（权限路径） / When 打开"我的身份与房屋"页并展开"我的房屋"二级菜单 / Then 页面上不存在"待我审批的同住人申请"卡片（不是显示"暂无"的空卡片），二级菜单中也没有"待我审批的同住人申请"项（Q-IP-13=A）
- AC-234-05：Given 用户 A 是 1 栋某户的产权业主，另有一条针对 2 栋某户（A 不是其产权业主）的待审批申请 / When A 打开该页 / Then 卡片中不含该申请；A 直接调用审批接口审批该申请时返回 403，提示"仅该专有部分产权业主可审批"，申请状态仍为待审批
- AC-234-06：Given 用户是 2 个专有部分的产权业主，两处各有 1 条待审批申请 / When 打开该页 / Then 卡片列出恰 2 行，分别对应两个专有部分（Q-IP-14=A）；同一专有部分有 2 位产权业主时，两位都能看到并审批同一条申请

### US-239: 用手机号注册或首次绑定手机号后，系统发现我名下的房屋并引导我确认
- 故事：As a 新注册用户或首次绑定手机号的用户（含微信登录用户、小程序用户）, I want to 在注册或绑定手机号后被引导到"认证产权"页并被询问"您是不是某某专有部分的业主", so that 我不用自己逐级找房屋、也不会被未经确认地绑定
- 关联需求：REQ-FUNC-233、REQ-FUNC-234、REQ-NFUNC-043；优先级：Must Have；故事点：8 [ESTIMATE]
- AC-239-01：Given 手机号 P 在清册中登记于"1栋1单元9层902号"（住宅）名下，新用户用 P 注册并通过验证码验证成功 / When 注册完成 / Then 页面进入"认证产权"引导页（而非直接进入主页），显示"我们发现您的手机号登记在 1栋1单元9层902号（住宅）名下，您是该专有部分的业主吗？"，并有"是，确认认证"与"不是"两个按钮；此时该用户在该专有部分上的有效关系数为 0
- AC-239-02：Given 同上 / When 引导页打开 / Then 该专有部分已被预选（楼栋、单元、楼层、户号与其一致），用户无需逐级选择
- AC-239-03：Given 手机号 P 不在清册中（边界路径） / When 注册成功 / Then 直接进入主页并提示"注册成功"，不出现引导页
