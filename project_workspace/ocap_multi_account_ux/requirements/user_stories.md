## 用户故事

### US-339: 账户管理页操作清晰可辨
- 故事：As a 管理员, I want to 在账户管理表格中清楚看到并点击"编辑""设为默认", so that 我不会因为按钮与背景同色而无法管理账户。
- 关联需求：REQ-FUNC-351、REQ-NFUNC-075；优先级：Must Have；故事点：2 [ESTIMATE]
- AC-410-01：Given 管理员进入"管理后台-财务-账户管理" When 表格渲染完成 Then "编辑"和"设为默认"的文字与其单元格背景对比度 ≥ 4.5:1，在默认主题下可直接辨认（截图 1 中"设为默认"近乎不可见的显示不再出现）。
- AC-410-02：Given 某行账户已是默认账户 When 查看该行操作列 Then "设为默认"呈不可用状态（不可点击、不可触发设为默认），且不可用态与可用态在视觉上可区分（文字对比度 ≥ 3:1 且样式不同）。

### US-340: 收入逐条录入时选择入账账户
- 故事：As a 业委会成员, I want to 在逐条录入收入时选择入账账户, so that 这笔收入记到正确的账户而不是一律进默认账户。
- 关联需求：REQ-FUNC-352、REQ-NFUNC-077；优先级：Must Have；故事点：3 [ESTIMATE]
- AC-411-01：Given 系统存在多个启用账户且默认账户为 A When 打开"逐条录入收入"对话框 Then 对话框中显示账户选择项，默认选中 A，下拉仅列出状态为启用的账户。
- AC-411-02：Given 用户在对话框中选择账户 B 并填写 1 条有效收入 When 点击"保存为草稿" Then 草稿成功创建且其入账账户为 B；在明细中可看到该收入表对应的账户为 B。
- AC-411-03：Given 系统没有任何启用账户 When 打开"逐条录入收入"对话框 Then 页面提示"暂无可用账户"，"保存为草稿"不可用，且不会发出创建请求。

### US-341: 收入表批量导入时指定整批账户
- 故事：As a 业委会成员, I want to 批量导入收入时先选定整批数据的账户, so that 导入的记录全部落到正确账户。
- 关联需求：REQ-FUNC-353、REQ-NFUNC-077；优先级：Must Have；故事点：3 [ESTIMATE]
- AC-412-01：Given 用户选择账户 B 并上传包含 3 条有效记录的文件 When 导入成功 Then 返回的导入草稿中 3 条记录的入账账户均为 B；审批通过后按账户查询可在 B 下查到这 3 笔。
- AC-412-02：Given 用户未选择账户 When 点击"批量导入"或选择文件 Then 页面提示"请先选择入账账户"，不发起上传/导入请求，也不产生草稿。

### US-342: 报销申请选择入账账户（Web）
- 故事：As a 业委会成员, I want to 提交报销时选择入账账户, so that 报销支出从正确账户扣减。
- 关联需求：REQ-FUNC-354、REQ-NFUNC-077；优先级：Must Have；故事点：2 [ESTIMATE]
- AC-413-01：Given 存在多个启用账户且默认账户为 A When 打开报销申请表单 Then 显示账户选择项且默认选中 A，可改选其他启用账户。
- AC-413-02：Given 用户选择账户 B 并填写合法报销信息 When 提交成功 Then 该报销申请关联账户 B；审批通过入账后，B 的余额减少相应金额而 A 不变。

### US-343: 备用金申请选择入账账户（Web）
- 故事：As a 业委会成员, I want to 申请备用金时选择入账账户, so that 预借现金从正确账户支出。
- 关联需求：REQ-FUNC-355、REQ-NFUNC-077；优先级：Must Have；故事点：2 [ESTIMATE]
- AC-414-01：Given 存在多个启用账户且默认账户为 A When 打开备用金申请表单 Then 显示账户选择项且默认选中 A。
- AC-414-02：Given 用户选择账户 C 并填写合法备用金信息 When 提交成功 Then 该申请关联账户 C；未选择账户时提交被阻止并提示"请选择入账账户"。

### US-344: 历史支出导入选择入账账户
- 故事：As a 业委会成员, I want to 历史支出批量导入时选择入账账户, so that 历史支出也记到正确账户。
- 关联需求：REQ-FUNC-356、REQ-NFUNC-077；优先级：Must Have；故事点：2 [ESTIMATE]
- AC-415-01：Given 打开"历史支出导入"页 When 页面渲染 Then 显示账户选择项，默认选中默认账户，仅列出启用账户。
- AC-415-02：Given 用户选择账户 B 并提交合法文件 When 该批次审批通过后 Then 批次内所有成功行的台账记录账户均为 B。
- AC-415-03：Given 用户未选择账户 When 提交导入 Then 页面提示"请选择入账账户"，不创建批次。

### US-345: 历史支出导入审批通过后才入账
- 故事：As a 业委会成员, I want to 历史支出导入先走审批，通过后才写台账, so that 历史数据进入账本前有多人确认。
- 关联需求：REQ-FUNC-357、REQ-NFUNC-077、C-386、C-387；优先级：Must Have；故事点：5 [ESTIMATE]
- AC-416-01：Given 用户已选择账户、上传合法文件并选择审批流程 When 提交导入 Then 生成状态为"审批中"的批次；此时台账中该批次记录数为 0，相关账户余额不变。
- AC-416-02：Given 该批次审批通过 When 查询批次明细与账户流水 Then 成功行已写入台账且账户为批次所选账户；重复/错误行保持原有"跳过并提示行号"的结果，不重复入账。
- AC-416-03：Given 该批次审批被驳回或提交人撤回 When 查询台账与账户余额 Then 该批次不产生任何台账记录、账户余额不变，且批次仍可在历史支出导入列表中查到其状态。
- AC-416-04：Given 某批次已被驳回 When 查看历史支出导入列表 Then 该批次状态显示"已驳回"且仍可查看；该批次的台账记录数为 0、账户余额不变。

### US-346: 财务报表账户卡片按宽度均匀排列
- 故事：As a 用户, I want to 账户卡片在页面上从左到右均匀铺开, so that 多账户信息不挤在左侧、右侧留白。
- 关联需求：REQ-FUNC-358、REQ-NFUNC-074；优先级：Must Have；故事点：3 [ESTIMATE]
- AC-417-01：Given 存在 3 个启用账户且浏览器视口宽度 ≥ 768px When 打开财务报表页 Then 3 张账户卡片从左到右等宽排列并铺满可用宽度，卡片区域右侧无大片空白，页面无水平滚动条。
- AC-417-02：Given 存在 8 个启用账户且视口宽度不足以同时展示 When 打开财务报表页 Then 账户卡片区域内部可横向滚动查看全部账户，卡片宽度不压缩到文字不可读，页面本身不出现水平滚动条。
- AC-417-03：Given 账户数量多到需要横向滚动 When 在卡片区横向滑动 Then "账户余额合计"标题与合计金额位置保持不动，仅账户卡片横向移动。

### US-347: 默认选中基本账户并可切换
- 故事：As a 用户, I want to 报表页默认选中基本账户并能点选其他账户, so that 我先看到常用账户，也能查看其他账户。
- 关联需求：REQ-FUNC-359、C-385；优先级：Must Have；故事点：3 [ESTIMATE]
- AC-418-01：Given 默认账户为 A 且存在启用账户 B、C When 打开财务报表页 Then A 的账户卡片呈选中态（有明确视觉标识，如边框/底色/标记），B、C 为未选中态，同一时刻仅一张卡片被选中。
- AC-418-02：Given 当前选中 A When 点击 B 的账户卡片 Then B 变为唯一选中态、A 取消选中，页面其余区域保持可用。
- AC-418-03：Given 某账户已被停用 When 刷新财务报表页 Then 该账户不出现在账户卡片列表中，也不能被选中。

### US-348: 季报/年报随选中账户切换
- 故事：As a 用户, I want to 报表列表显示当前选中账户的数据, so that 我能看到每个账户自己的季报/年报金额。
- 关联需求：REQ-FUNC-360、REQ-NFUNC-077；优先级：Must Have；故事点：5 [ESTIMATE]
- AC-419-01：Given 默认账户为 A When 打开财务报表页 Then 下方报表条目展示的收入、支出、结余为 A 的口径（与报表详情按 A 取数的结果一致）。
- AC-419-02：Given 当前选中 A 且已设置周期筛选"仅季报" When 点击账户 B 的卡片 Then 列表刷新为 B 口径，周期筛选仍为"仅季报"；若当前页码超出新的总页数则回到第 1 页。

### US-349: 报表详情去掉账户下拉并跟随页面账户
- 故事：As a 用户, I want to 打开报表后不再重复选账户, so that 详情与我在页面上选的账户保持一致。
- 关联需求：REQ-FUNC-361、C-388；优先级：Must Have；故事点：2 [ESTIMATE]
- AC-420-01：Given 报表页当前选中账户 B When 点击任一条报表打开详情浮层 Then 浮层内不存在账户下拉菜单或"全部账户"选项。
- AC-420-02：Given 报表页当前选中账户 B When 详情加载完成 Then 期初结余、本期收入、本期支出、期末结余与明细均为 B 的口径，且与 B 卡片余额变化一致。

### US-350: 报表详情收支颜色区分
- 故事：As a 用户, I want to 在报表明细中一眼区分收入和支出, so that 我不用逐行读文字判断方向。
- 关联需求：REQ-FUNC-362、REQ-NFUNC-076；优先级：Must Have；故事点：2 [ESTIMATE]
- AC-421-01：Given 报表详情同时含收入行与支出行 When 明细表渲染 Then 收入行的"收入"文字与金额使用收入色，支出行的"支出"文字与金额使用支出色，两色不同；且与账户卡片流水中同方向的颜色一致。
- AC-421-02：Given 报表详情只有支出行（无收入行） When 明细表渲染 Then 所有行均使用支出色，"方向"列仍显示"支出"文字；本期无明细时展示"本期暂无收支明细"空态且不报错。
- AC-421-03：Given 报表详情已加载 When 查看指标卡 Then "本期收入"的数值使用收入色、"本期支出"的数值使用支出色，且与明细同方向颜色一致。

### US-351: 历史支出导入被驳回后重新导入
- 故事：As a 业委会成员, I want to 在导入批次被驳回后重新发起新批次, so that 修正数据后仍能完成入账且旧批次可追溯。
- 关联需求：REQ-FUNC-363、C-387；优先级：Must Have；故事点：2 [ESTIMATE]
- AC-422-01：Given 某批次已被驳回 When 打开历史支出导入列表 Then 该批次显示"已驳回"并可查看其驳回结果，台账中该批次记录数为 0、账户余额不变。
- AC-422-02：Given 存在已驳回批次 When 用户选择文件重新导入并提交审批 Then 系统创建新的批次（批次标识与原批次不同），原批次保持"已驳回"；新批次审批通过后只新批次入账，原批次不重复入账。

### US-352: 小程序报销申请选择入账账户
- 故事：As a 业委会成员, I want to 在小程序提交报销时选择入账账户, so that 移动端提交的报销也记到正确账户。
- 关联需求：REQ-FUNC-364、REQ-NFUNC-078；优先级：Must Have；故事点：2 [ESTIMATE]
- AC-423-01：Given 存在多个启用账户且默认账户为 A When 在小程序打开报销表单 Then 显示账户选择项，默认选中 A，可选项仅包含启用账户。
- AC-423-02：Given 用户未选择账户 When 点击提交 Then 小程序提示"请选择入账账户"且不发请求；Given 选择账户 B 并提交成功 When 审批通过入账 Then 报销关联账户 B，B 的余额减少而 A 不变。

### US-353: 小程序备用金预借选择入账账户
- 故事：As a 业委会成员, I want to 在小程序申请备用金时选择入账账户, so that 预借现金从正确账户支出。
- 关联需求：REQ-FUNC-365、REQ-NFUNC-078；优先级：Must Have；故事点：2 [ESTIMATE]
- AC-424-01：Given 存在多个启用账户且默认账户为 A When 在小程序打开备用金预借表单 Then 显示账户选择项，默认选中 A，可选项仅包含启用账户。
- AC-424-02：Given 用户未选择账户 When 点击提交 Then 提示"请选择入账账户"且不发请求；Given 选择账户 C 并提交成功 When 审批通过入账 Then 该备用金关联账户 C。
