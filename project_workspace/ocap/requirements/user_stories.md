### 域 A：注册与登录

### US-001: Web 端手机号 + 验证码注册
- 故事：As a 访客, I want to 仅用手机号和短信验证码在 Web 端完成注册（可选填邮箱）, so that 我无需设置密码即可拥有账号
- 关联需求：REQ-FUNC-001；优先级：Must Have；故事点：5 [ESTIMATE]
- AC-001-01：Given 访客输入未注册的手机号并获取了短信验证码 / When 访客提交正确且在有效期内的验证码（不填邮箱） / Then 系统创建账号并生成账号标识，访客处于已登录状态，该用户身份为游客，注册过程中未要求设置密码
- AC-001-02：Given 访客输入未注册的手机号并获取了短信验证码 / When 访客提交错误的验证码，或提交已超过有效期（短信 5 分钟）的验证码 / Then 注册失败、不创建账号，界面提示验证码错误或已过期；同一验证码输错 5 次即作废，须重新获取；同一手机号 30 分钟内累计输错 10 次，该手机号被锁定 30 分钟，锁定期内即使提交正确验证码也被拒绝（REQ-NFUNC-001、C-06）
- AC-001-03：Given 访客注册时填写了邮箱 / When 注册成功 / Then 该邮箱仅作为未验证的资料项保存，不因注册而视为验证通过（验证见 US-007）
- AC-001-04：Given 访客输入的手机号已属于一个有效账号 / When 访客提交注册 / Then 系统不创建新账号，提示该手机号已注册并引导登录
- AC-001-05：Given 同一手机号刚获取过一次短信验证码 / When 在 60 秒内再次获取，或该手机号当小时已获取 5 条、当天已获取 10 条后再次获取，或同一来源 IP 当小时已获取 30 条后再次获取 / Then 系统拒绝再次发送并提示稍后重试（REQ-NFUNC-001、C-06）；验证码为 6 位纯数字
- AC-001-06（4.1.0 新增，C-19）：Given 访客输入的号码不是中国大陆 11 位手机号（如位数不足、含非数字字符、国际区号号码） / When 提交获取验证码或注册 / Then 被拒绝，不发送验证码、不创建账号，界面提示仅支持中国大陆 11 位手机号

### US-002: Web 端微信扫码登录
- 故事：As a 访客, I want to 在 Web 端用微信扫码登录, so that 我无需输入手机号或密码
- 关联需求：REQ-FUNC-002；优先级：Must Have；故事点：5 [ESTIMATE]

### US-039: 业委会/业主代表身份的唯一性、不可兼任与自动失效
