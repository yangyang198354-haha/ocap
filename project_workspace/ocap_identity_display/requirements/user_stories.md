## 用户故事

### US-145: 主页“当前身份”按三类身份正确显示

- 故事：As a 已登录的用户, I want to 在主页“当前身份”模块看到我当前唯一有效的身份（游客 / 产权业主 / 同住人）, so that 我能确认自己是否已完成业主身份认证
- 关联需求：REQ-FUNC-136、REQ-FUNC-137、REQ-FUNC-138、C-34；优先级：Must Have；故事点：5 [ESTIMATE]
- AC-145-01：Given 用户已登录且没有任何有效房屋关系、也没有业委会职务 / When 打开用户端主页 / Then “当前身份”显示“游客”，且不显示“户主”“产权业主”“同住人”中任何一个
- AC-145-02：Given 用户的手机号与某专有部分清册业主手机号一致并已完成认证（内部角色为 HEAD 或 OWNER） / When 打开主页 / Then “当前身份”显示“产权业主”，不显示“户主”
- AC-145-03：Given 用户通过产权申诉上传产权证明且管理员审核通过 / When 打开主页 / Then “当前身份”显示“产权业主”
- AC-145-04：Given 用户经产权业主审批通过成为某专有部分的同住人，且没有其他有效产权关系 / When 打开主页 / Then “当前身份”显示“同住人”
- AC-145-05：Given 用户在一套房屋是产权业主、在另一套房屋是同住人 / When 打开主页 / Then “当前身份”只显示“产权业主”，不同时显示“同住人”
- AC-145-06：Given 用户此前的产权认证已被管理员撤销、同住人关系已退出，且无其他有效关系 / When 打开主页 / Then “当前身份”显示“游客”，不残留任何历史身份
- AC-145-07：Given 用户是产权业主且持有有效的业委会主任（或副主任）席位 / When 打开主页 / Then “当前身份”只显示“主任”（或“副主任”），不叠加“产权业主”，也不出现“户主”
- AC-145-08：Given 用户是产权业主且持有有效的业委会委员席位或业主代表席位 / When 打开主页 / Then “当前身份”只显示“委员”或“业主代表”
- AC-145-09：Given 用户的业委会职务已到期、被撤销或资格失效，但仍有一套有效产权关系 / When 打开主页 / Then “当前身份”显示“产权业主”，不显示已失效的职务
- AC-145-10：Given 用户只绑定了一套房屋且已认证 / When 打开主页 / Then “当前身份”只显示一个身份词，不出现“产权业主、产权业主”这类重复

### US-146: 认证房屋模块显示每套房屋的名称、类型与面积

- 故事：As a 已认证的业主或同住人, I want to 在主页“认证房屋”模块看到已绑定专有部分的数量以及每套的名称、类型和面积, so that 我能确认自己绑定的具体房屋与登记信息
- 关联需求：REQ-FUNC-139、REQ-FUNC-140、REQ-NFUNC-025；优先级：Must Have；故事点：5 [ESTIMATE]
- AC-146-01：Given 用户绑定 1 套专有部分，名称“1栋1单元9层902号”、类型住宅、面积 89.5 / When 打开主页 / Then “认证房屋”显示数量 1，并显示一行明细：名称“1栋1单元9层902号”、类型“住宅”、面积“89.50 ㎡”
- AC-146-02：Given 用户绑定 3 套专有部分 / When 打开主页 / Then 数量显示 3，三套全部展示，并按专有部分名称升序排列
- AC-146-03：Given 用户绑定的是一个车位（无单元/楼层结构） / When 打开主页 / Then 明细显示车位的完整名称、类型“车位”与其面积，名称不出现“undefined”“null”或空括号
- AC-146-04：Given 某套专有部分的类型未登记 / When 打开主页 / Then 该套类型显示“未登记”，面积仍按登记值显示
- AC-146-05：Given 某套专有部分的面积未登记 / When 打开主页 / Then 该套面积显示“未登记”，不显示“0 ㎡”
- AC-146-06：Given 用户没有任何有效房屋关系 / When 打开主页 / Then “认证房屋”数量显示 0，并显示空状态文案（如“暂无已认证房屋”），不显示空列表占位行
- AC-146-07：Given 用户原有 2 套认证，其中 1 套已被撤销 / When 打开主页 / Then 数量显示 1，明细只显示仍有效的那 1 套
- AC-146-08：Given 用户以同住人身份绑定某套房屋 / When 打开主页 / Then 该套出现在明细中并标注“同住人”，产权业主房屋标注“产权业主”
- AC-146-09：Given 用户绑定多套且名称相同（同名不同 ID 不应出现） / When 打开主页 / Then 同一专有部分只出现一次，数量与明细行数一致

### US-147: 身份与房屋信息的加载态与有效性

- 故事：As a 已登录的用户, I want to 主页在身份与房屋数据加载完成前不显示错误的身份或数量, so that 我不会被先出现的“游客 / 0 套”误导
- 关联需求：REQ-NFUNC-024、REQ-NFUNC-026；优先级：Should Have；故事点：3 [ESTIMATE]
- AC-147-01：Given 用户是已认证产权业主，主页开始加载、身份数据尚未返回 / When 页面首次渲染 / Then “当前身份”与“认证房屋”显示加载占位，不显示“游客”或数量 0
- AC-147-02：Given 身份数据请求失败（网络错误或服务异常） / When 页面渲染完成 / Then 身份与房屋区域显示“加载失败，请重试”类提示与重试入口，不把用户显示为“游客”
- AC-147-03：Given 用户存在已结束的产权关系（ended_at 非空） / When 打开主页 / Then 该关系不计入身份判断，也不出现在认证房屋明细与数量中

### US-148: Web 与小程序的身份和房屋信息保持一致

- 故事：As a 使用多个入口的用户, I want to 在 Web 用户端与小程序看到相同的身份与认证房屋信息, so that 我不会因为入口不同而看到矛盾的身份
- 关联需求：REQ-FUNC-141；优先级：Must Have；故事点：3 [ESTIMATE]
- AC-148-01：Given 同一账号在 Web 与小程序均已登录 / When 分别打开两个入口的主页 / Then 两端的“当前身份”文案完全一致
- AC-148-02：Given 同一账号绑定 2 套房屋 / When 分别打开两个入口的主页 / Then 两端“认证房屋”数量都为 2，且每套的名称、类型、面积一致
- AC-148-03：Given 账号无任何有效房屋关系 / When 分别打开两个入口的主页 / Then 两端都显示“游客”与数量 0，空状态文案含义一致
- AC-148-04：Given 用户在 Web 完成清册认证后立即切到小程序主页 / When 小程序主页加载完成 / Then 显示“产权业主”，不显示过期的“游客”
