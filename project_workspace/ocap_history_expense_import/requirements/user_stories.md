## 用户故事

### US-333: 下载历史支出导入模板
- 故事：As a 业委会成员, I want to 下载历史支出导入模板, so that 我可以按固定列填写过去几年的支出。
- 关联需求：REQ-FUNC-342；优先级：Must Have；故事点：2 [ESTIMATE]
- AC-333-01：Given 业委会成员已登录并进入历史支出导入页 / When 点击“下载模板”并选择 xlsx / Then 下载文件名为“历史支出导入模板.xlsx”，第一个工作表首行为“日期、金额、支出类别、用途/事由、备注”五列，且另含“填写说明”工作表。
- AC-333-02：Given 业主代表、产权业主、同住人、游客或后台管理员 / When 请求模板下载接口 / Then 已登录的非业委会成员返回 403，未登录返回 401，响应不包含模板文件内容。

### US-334: 批量导入历史支出
- 故事：As a 业委会成员, I want to 上传历史支出文件并逐笔写入台账, so that 往年报表能包含真实的历史支出。
- 关联需求：REQ-FUNC-343、REQ-FUNC-344、REQ-FUNC-345、REQ-FUNC-346；优先级：Must Have；故事点：5 [ESTIMATE]
- AC-334-01：Given 文件含 3 行合法历史支出（日期分别为 2022-07-01、2024-03-15、2026-09-30）/ When 上传并确认导入 / Then 创建 1 个导入批次，成功行数=3；台账新增 3 条支出明细，日期、金额与文件一致，标记为历史导入并关联该批次；系统中不新增报销/备用金/核销申请、不新增审批实例、审批待办数量不变。
- AC-334-02：Given 文件含合法行与错误行（日期为空/日期不存在/金额为 0/金额为负/金额三位小数/类别超过 32 字）/ When 导入 / Then 合法行照常导入，每个错误行返回行号与具体原因，失败行数等于错误行数；若所有行都错误，则不创建批次、不写任何台账明细。
- AC-334-03：Given 文件内两行或文件与已有有效历史支出的“日期+金额+支出类别+用途”四项完全相同 / When 导入 / Then 重复行被跳过并返回行号，只写入不重复的行；仅备注不同不视为重复。
- AC-334-04：Given 文件超过 5MB 或数据行超过 5000 行 / When 上传 / Then 返回 413 或 400，提示文件过大/行数超过上限，不创建批次；xlsx 含多个工作表时只读取第一个工作表。
- AC-334-05：Given 文件缺少“日期/金额/支出类别/用途/备注”中任一列，或某行日期晚于今天 / When 导入 / Then 缺少列时返回 400 并列出缺失列；未来日期行按错误行跳过并提示行号。

### US-335: 查看历史支出导入批次与明细
- 故事：As a 业委会成员, I want to 查看每次导入的批次和逐行结果, so that 我能核对金额与失败原因。
- 关联需求：REQ-FUNC-347；优先级：Should Have；故事点：3 [ESTIMATE]
- AC-335-01：Given 已有导入批次 / When 打开历史支出批次列表 / Then 每行显示批次时间、操作人、文件名、总行数、成功行数、跳过/失败行数、金额合计、状态；金额合计等于该批次有效台账明细金额之和。
- AC-335-02：Given 打开某批次明细 / When 查看列表 / Then 每行显示日期、金额、支出类别、用途/事由、备注、处理结果（成功/重复/错误及原因）；非业委会成员访问返回 403。

### US-336: 整批作废历史支出
- 故事：As a 业委会成员, I want to 作废一整批导错的历史支出, so that 报表不被错误数据污染。
- 关联需求：REQ-FUNC-350；优先级：Should Have；故事点：3 [ESTIMATE]
- AC-336-01：Given 某历史支出批次已写入台账 / When 有权限用户确认“整批作废”并填写原因 / Then 该批次全部台账明细状态变为“已作废”，批次状态变为“已作废”，覆盖这些日期的已生成报表被标记为过期，并产生一条含操作人、时间、原因、行数、金额合计的审计记录。
- AC-336-02：Given 批次已作废 / When 再次作废 / Then 返回 409 且不重复写审计；作废后允许重新导入同一批数据；非业委会成员作废返回 403。

### US-337: 基于历史支出生成往年报表
- 故事：As a 业委会成员, I want to 生成 2022Q3～2026Q3 的季度/年度报表, so that 业委会和业主能看到完整的历史收支。
- 关联需求：REQ-FUNC-348；优先级：Must Have；故事点：3 [ESTIMATE]
- AC-337-01：Given 历史支出已导入台账 / When 业委会成员生成 2022 年第 3 季度报表 / Then 报表 total_expense 等于该季度有效台账支出明细之和，明细中包含历史支出记录及其来源标记。
- AC-337-02：Given 报表已生成 / When 产权业主、同住人、游客或业主代表查看报表 / Then 可查看报表汇总与明细；未登录请求返回 401。
- AC-337-03：Given 某批次已作废 / When 重新生成受影响季度的报表 / Then 报表不再包含该批次金额，total_expense 相应减少。

### US-338: 历史支出功能的权限隔离
- 故事：As a 系统管理员/业委会成员, I want to 限制历史支出导入只对业委会成员开放, so that 财务数据不被无权限角色写入。
- 关联需求：REQ-FUNC-349；优先级：Must Have；故事点：2 [ESTIMATE]
- AC-338-01：Given 现任主任、副主任或委员 / When 访问模板下载、导入、批次列表、作废接口 / Then 均返回成功（模板/导入 200/201，批次 200）；业主代表、产权业主、同住人、游客、后台管理员访问同一接口返回 403（未登录 401）。
- AC-338-02：Given 非业委会成员登录 Web / When 查看导航与历史支出页面 / Then 不显示“历史支出导入”入口；直接访问页面时展示无权限提示，不发起导入请求。
