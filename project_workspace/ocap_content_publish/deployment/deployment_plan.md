## 连接与变量（E2 开头执行一次）

外网通道连续新建连接会被断开（R2 遇到 4 次 `Connection closed`）。因此用一条 ControlMaster 长连接复用所有 ssh/scp，建立连接时有限次重试（≤5 次，间隔 20 秒）。**只对"建立连接"重试；已开始执行的非幂等命令若返回 255，先只读核对目标机状态再决定，不盲目重发。**

```bash
# 开发机（Claude 主会话云主机）仓库根，bash
REL=955c63a                                   # 本次发布提交（PRE-001 核对完整哈希）
BASE_REL=a0a0b3a                              # 目标机当前版本
OCAP_HOST=47.109.197.217; OCAP_PORT=57279; OCAP_USER=yangyang
WORK=$(mktemp -d); KH=$WORK/known_hosts       # 本地临时目录：known_hosts 与 ControlMaster 套接字
ssh-keyscan -p $OCAP_PORT -t ed25519 $OCAP_HOST > $KH 2>/dev/null
ssh-keygen -lf $KH                            # 指纹必须 = SHA256:TfpCSrSLuK1UspD2mpikebK0bE0IFnPH8bSigERWnmk，否则停止
SSH_OPTS="-o UserKnownHostsFile=$KH -o StrictHostKeyChecking=yes -o ControlPath=$WORK/cm-%C -o ServerAliveInterval=20"
OCAP_SSH="ssh -p $OCAP_PORT $SSH_OPTS $OCAP_USER@$OCAP_HOST"   # 使用时不加引号
OCAP_SCP="scp -P $OCAP_PORT $SSH_OPTS"                         # scp 端口为大写 -P
OCAP_DEST="$OCAP_USER@$OCAP_HOST"
ocap_connect() {                              # 建立/确认长连接
  for i in 1 2 3 4 5; do
    ssh -p $OCAP_PORT $SSH_OPTS -O check $OCAP_DEST 2>/dev/null && return 0
    ssh -p $OCAP_PORT $SSH_OPTS -o ControlMaster=yes -o ControlPersist=20m -fN $OCAP_DEST && return 0
    echo "connect attempt $i failed; sleep 20"; sleep 20
  done; return 1; }
ocap_connect || echo "无法建立 SSH 连接：目标机无任何变更，报 DEPLOYMENT_FAILED"
```

引号约定（出错会让回滚静默失效）：
- 含本地变量（`TS`、`REL`、sha256）的远端命令一律用 `$OCAP_SSH bash -s -- "$TS" ... <<'EOF' … EOF`：heredoc 分隔符加引号，脚本体里的 `$VAR` 由远端 bash 展开，本地值只经位置参数 `$1 $2…` 传入。这样没有"单引号里的 `$TS` 在远端为空"的问题。
- 不含变量的单行命令用 `$OCAP_SSH '…'`；含 `$TS` 的单行命令用双引号并先 `echo` 核对。
- `$OCAP_SSH` 不加引号使用（依赖分词）。
- 禁止 `cat .env`、禁止 `set -x`（会回显密钥）、禁止把 `.env` 内容写入任何本地文件；校验只用 `grep -c` 键名计数。
