### US-207: Web 登录/注册页与网页标题改为 Cyber@红枫岭（变更：补充管理端标题）

- 关联需求：REQ-FUNC-201、REQ-FUNC-202；优先级：Must Have；故事点：3 [ESTIMATE]
- AC-207-01：Given 未登录用户打开 `/login` / When 页面渲染完成 / Then 页面可见标题含字面"Cyber@红枫岭"，且不再出现"业主委员会 · 登录"；验证码/密码/邮箱 3 个登录方式、"手机号注册"链接与登录流程与改动前一致

- AC-207-03：Given 用户在 `/login`、`/register`、登录后任一用户端页面之间切换 / When 读取 `document.title` / Then 值恒为"Cyber@红枫岭"（Q-BL-14=A），不是"业主委员会"
- AC-207-04：Given 管理员打开 `/admin/login` 并登录进入 `/admin/registry` / When 在两页分别读取 `document.title` / Then 两处均为"Cyber@红枫岭"（Q-BL-01=B 同改）；管理端登录与令牌行为不变，用户端已登录状态不受影响（异常/范围路径）
